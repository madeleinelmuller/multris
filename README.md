# multris

A local multiplayer Tetris built with Pygame.

## Requirements

- Python 3.8+
- [Pygame](https://www.pygame.org/) (install with `pip install -r requirements.txt`)

## Usage

Run the game:

```bash
python tetris.py
```

### Controls

Player 1:

- Arrow keys to move and rotate
- `Return` or Right Ctrl for hard drop

Player 2:

- `W`, `A`, `S`, `D` to rotate and move
- Space for hard drop

Press the window close button to exit.
